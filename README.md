# Games

Small browser puzzles. Each one is a single static page. No accounts and nothing to run on a server. More games will be added over time.

Play: [https://games.shib.me](https://games.shib.me)

## Tango

A 6x6 sun and moon logic puzzle. Every row and column gets three suns and three moons. You cannot put three of the same in a line. Marks between cells say whether they must match or differ.

Classic levels are included. Generated mode builds new puzzles in the browser at easy, medium, or hard.

## Casebook

A cozy detective anthology with alibi grids, contradictory testimony, and evidence-board deductions. Read each case, keep a logical notebook, then name both the culprit and the proof.

Twelve authored mysteries are included. Generated mode builds replayable, uniquely solvable cases from shareable seeds.
